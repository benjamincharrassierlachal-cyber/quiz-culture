# Le test fermé — 12 testeurs, 14 jours

## La règle exacte

Google demande, pour un compte personnel, **au moins 12 testeurs inscrits en continu pendant
14 jours**, avec une activité réelle, avant d'autoriser la production.

Trois pièges :

1. **Inscrire ≠ participer.** Ajouter l'adresse dans la Console ne suffit pas : la personne doit
   ouvrir le lien d'inscription, accepter, puis installer le jeu depuis le Play Store.
2. **Le compte doit être le bon.** L'adresse Gmail donnée doit être celle réellement connectée sur
   le téléphone Android. Une adresse non-Gmail ne fonctionne pas du tout.
3. **Le compteur repart à zéro** si on descend sous 12. D'où les 14 adresses collectées.

## La liste

Fichier `testeurs.txt`, une adresse par ligne, rien d'autre — c'est le format que la Console accepte
au copier-coller dans *Test → Test fermé → Testeurs → Créer une liste d'adresses e-mail*.

## Le message à envoyer

Lien d'inscription (version Web, celle qui affiche un message clair en cas d'erreur) :

```
https://play.google.com/apps/testing/com.b1jam1c.quizzdubac
```

Lien de secours, pour ceux qui bloquent, à ouvrir depuis le téléphone :

```
https://play.google.com/store/apps/details?id=com.b1jam1c.quizzdubac
```

J'ai développé un jeu de quiz, **Le Quizz du BAC** : on part du CP et on essaie de décrocher le bac,
question après question. Avant de pouvoir le publier sur le Play Store, Google exige que douze
personnes le testent pendant deux semaines. C'est là que j'ai besoin de toi.

Trois choses à faire, cinq minutes en tout :

1. Ouvre ce lien : **https://play.google.com/apps/testing/com.b1jam1c.quizzdubac**
2. Appuie sur « Devenir testeur », puis sur le lien du Play Store qui apparaît.
3. Installe le jeu et fais au moins une partie. Si le mode BAC est trop difficile, il te suffit de
   faire pause et d'enregistrer ton score ; le mode détente est sympa aussi.

Trois points importants :

- Dans le Play Store, le jeu s'appelle **Quizz Culture Générale & BAC** — c'est bien le bon.
- Le lien doit être ouvert avec l'adresse Gmail que tu m'as donnée, celle de ton téléphone. Avec une
  autre adresse, la page affichera une erreur.
- Surtout, **ne désinstalle pas le jeu avant le 1er septembre** : Google vérifie que douze personnes
  l'ont installé sans interruption pendant quatorze jours. Un seul départ et je repars de zéro.

Le jeu est normalement payant, mais il est gratuit pour toi : ton adresse est enregistrée comme
testeur. Si le Play Store te réclame de l'argent, ne paie pas et préviens-moi, c'est que j'ai raté
quelque chose.

Si quelque chose bloque, dis-le-moi, je regarde. Et si tu trouves un bug ou une question fausse,
écris-moi à quizzdubac@gmail.com : c'est exactement ce que j'attends de ce test.

Merci beaucoup,
